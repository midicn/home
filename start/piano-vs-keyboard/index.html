「买钢琴还是买键盘？」——这问题的答案，先取决于你想要的其实是哪一件东西。它们名字相近，设计目标完全不同。

先回答三个问题

1. 你学的是「钢琴」还是「键盘」？ 想弹古典曲目、要练触键——选配重键盘（真钢或电钢）；想做编曲、玩音色——键盘更合适。 2. 你的空间和邻居是什么局面？ 公寓 + 晚练 → 电钢（耳机）几乎是唯一解。 3. 五年内你会搬家吗？ 声学钢琴的搬运成本很高，电钢可以背着走。

一个务实的建议

预算有限、方向未定：先买电钢。它的手感足以支撑到中高级的绝大部分内容，还附带静音与便携。等你确定「这辈子要跟古典钢琴死磕」或者「家里有稳定的空间」，再考虑声学钢琴——那时你会买得更准。

关于「手感」的一个实话

手感是键盘乐器的核心参数，而它只能用手测，不能看参数。去琴行，弹三种：配重的电钢、真钢琴、无配重的键盘——五分钟你就有答案。

听一听：相邻的两个键，是音乐最小的距离

键盘乐器的布局本身就是乐理图：相邻两个键之间就是最小的距离——半音。听听这两个「隔壁邻居」合起来的样子，这就是键盘帮所有人理解音乐的方式。
