二手乐器怎么挑

便宜要靠一张检查清单兑现——外行也能做的六个动作

约 2 分钟589 字条目更新 2026-09-28

乐器二手选择

相关

古典吉他小提琴标准音高

乐器是二手市场最正常的品类之一：乐器保值性好、很多人一两年就更新、旧琴常被低估。但「便宜」不会自动变成「划算」——它要靠一张检查清单来兑现。

哪些适合买二手

  • 适合：结构简单、标准化程度高的乐器——吉他、电钢、多数管乐、小提琴（量大）。
  • 谨慎：易损耗件占比高的（簧片类）、电子元件老化的（老合成器）、以及需要专业评估才能定价的（老钢琴——请调音师同行）。

外行也能做的六个动作

1. 白天看琴：光线充足，瑕疵藏不住。 2. 弹一遍试琴曲目（见下方三段）：听三点——有没有杂音/每个音一样大声吗/高音区刺耳吗。 3. 查物理伤：吉他看琴颈直不直（从琴头瞄向琴身）、琴桥有没有开胶；管乐看管身凹陷、垫圈是否老化发硬；弦乐看面板裂缝（对光看）。 4. 看磨损与使用痕迹：品丝凹痕、按键磨损、漆面——用了多久，比卖家说的时间更诚实。 5. 验序列号：和卖家核对序列号与票据；来源可疑的便宜，坚决不要（可能是赃物）。 6. 做价格锚点：搜同款近期的成交价，横向比三家——不要拿「全新价」当参照。

一段「试琴曲目」怎么准备

带三段去试琴（哪怕是手机里的录音）：

  • 一段独奏——暴露音准与手感；
  • 一段练习曲——检验每个音区的均匀度；
  • 一段你喜欢的音乐——它会告诉你「你是不是真的想带它回家」。

交易时的两个不要

  • 不要没试过就付款（哪怕同城闪送）；
  • 不要为「故事」付溢价（它是谁的老师用过不重要，只认乐器本身的状态与价格）。

听一听：一个「干净」的五度

音准可以粗验：好的纯五度听起来是「干净」的——两个音像融在一起。下面这条是标准听感，用它在现场对照。

下一步

  • 弦乐器很值得淘：小提琴 的状态怎么读。
  • 音准的基准线是什么：标准音高。
