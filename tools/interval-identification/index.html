首页›音程听辨练习：先听得出，再说出名字

这一页不教你新东西，只给你一套能自己练的流程。如果你已经会唱音名但还是听不出来，问题不在知识。

瓶颈在哪：三层

听辨能力分三层，多数人卡在第 2 与第 3 之间：

1. 听得出有区别 —— 能判断两个音一样或不一样； 2. 听得出是什么 —— 能说出它是大三度还是纯五度； 3. 心里能唱出来 —— 能在没有声音的情况下在脑内重建它。

第 3 层是瓶颈。 因为辨认可以靠排除法（"比大三度小"），但唱歌必须精确到具体两个音。

所以下面的练习全部围绕第 3 层设计。

一个可执行的练习流程

1. 只点「合起来」，不要分别听——分别听会让答案变成"两个音的印象"，而不是"距离的印象"； 2. 在心里把它唱一遍（第 3 层）； 3. 唱得出来，再点分别听，验证； 4. 唱不出来的那一组，就是你要练的那一组——不是全部都要练。

第 4 步是整个流程的关键。 大多数人练音程失败的原因是"从头到尾都练"，而正确做法是只练唱不出来的那几个。

一个常见误解要澄清

「我听不出大三度和小三度」不是耳朵有问题。真实原因是：

  • 缺少参照——没人告诉你"大三度听起来该是这样"；
  • 只听不做——听得再多，不在脑内重建就永远不牢。

这两个问题都能靠上面的流程解决，不需要换耳朵。

进度会卡在一个地方

练耳的进展不是线性的。常见轨迹是：初期进步快 → 平台期 → 突破。

平台期通常就发生在"能听出但唱不准"的位置——也就是第 2 层到第 3 层之间。

这不是天赋问题，是训练目标切换。 过了这关，后面的进展会重新变快。
