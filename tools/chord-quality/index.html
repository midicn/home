三和弦的三种性质：大、小、减

三种性质的区别就是中间那两个音的距离

约 2 分钟666 字条目更新 2026-10-03

工具听辨和弦

三和弦只有三种性质，但很多人听一辈子都分不清。这一条想告诉你：区别只有一个东西——中间那个音离根音多远。

三种性质，各听一次

第一种：大三和弦（根音上 0 / 4 / 7 个半音）

第二种：小三和弦（0 / 3 / 7）

第三种：减三和弦（0 / 3 / 6）

关键：只有中间那个音在动

上面三组，根音（C）和最高音（G 或 B♭）几乎没变，变的是中间：

性质根音中间音最高音
大CE（+4）G
小CE♭（+3）G
减CE♭（+3）B♭（+6）

这解释了为什么你能在钢琴上"看见"大小三和弦是同一个手型。 因为它们真的是同一个手型，只是手指落的位置差半个键。

而减三和弦不一样——它的高音也降了（变成降七度）。所以减三和弦听起来才那么"紧"。

一个可自己验证的动作

1. 先只听第一组（大）的「分解」； 2. 再只听第二组（小）的「分解」； 3. 交替快速听——你会发现那两个中间音（E 与 E♭）在你脑子里开始"对调"。

这个"对调"的感觉就是听辨能力的建立。 和音程那篇的方法完全一样。

三种性质分别在音乐里干什么

  • 大三：稳定的、开放的、开始或结束；
  • 小三：暗的、忧的、向下走的倾向；
  • 减三：极不稳定，它的作用是要解决到别的地方去。

关键理解：减三和弦不是一种"色彩"，它是一个"问题"。 它几乎总是出现在要回家之前的那一刻（属到主、导音到主）。

所以当你听到减三和弦时，正确反应不是"这是什么颜色"，而是"它要去哪"。

一个诚实的边界

这一条只讲三和弦。七和弦、挂留、加音这些都建立在三和弦之上——理解了"中间那个音在动"这个思路，其余都是类似的加法。

下一步

  • 加一个音变出什么：七和弦
  • 换个位置听起来一样吗：转位
  • 还没解决的那一秒：挂留与变化音
  • 三种性质的实际组合：三个最常见的和声进行
