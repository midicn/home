五度圈：十二个调的地图

相邻两格是纯五度，顺时针升号增加——整张图只是一把「距离尺」

约 2 分钟852 字条目更新 2026-10-03

工具调性键盘

上面有一个可以点的五度圈。点任意一格，听那个调的主三和弦；顺时针点一圈，听一遍十二个调。

这一条要说的是：这张图不是「十二个调的位置表」，它是一把尺子。

先点一圈：这就是那张尺子

下面是可点的五度圈。点任意一格，听那个调的主三和弦；顺时针点一圈，听一遍十二个调。

先试一件事：顺时针点一圈

你会发现两件事：

1. 相邻两格之间的差别很小 —— 升号只多一个； 2. 但到对面那一格时，差别最大 —— 六个升号对六个降号。

这就是五度圈的核心：它把「调之间的距离」变成了一张可读的图。

圈的三条规则

1. 相邻两格 = 纯五度

从 C 顺时针到 G，是一个纯五度；G 到 D 又是一个纯五度。

纯五度是最协和的音程 —— 所以相邻两格的调「关系最近」。这就是为什么转调时沿着圈走一步是最小代价。

2. 顺时针 = 升号增加，逆时针 = 降号增加

  • 从 C 顺时针：C → G（1♯）→ D（2♯）→ A（3♯）……
  • 从 C 逆时针：C → F（1♭）→ B♭（2♭）→ E♭（3♭）……

所以这个圈同时是一张「调号表」。 每一格的调号数量就是它离 C 的距离。

3. 对角线 = 关系调

在圈上隔三格（也就是对角）的两个调，关系特殊：

  • 关系大调 / 小调：C–A 小调、E–C# 小调；
  • 同名大小调（不在这张图上，因为在同一条线的两端）。

关系小调只差三个半音，但它在圈上隔了三格 —— 因为关系大小调是「同一个主音的两个版本」。

一个常见误解要澄清

「离 C 越远，越「亮」」这句话只对了一半。

准确的说法：五度圈只告诉你调号数量，不告诉你亮暗。

  • C 大调（0 个升降号）听起来最「中性」；
  • G 大调（1 个升号）比它亮一点；
  • F# 大调（6 个升号）是最亮的——但它离 C 最远。

所以「亮」跟「离 C 远」是两件事。 圈上的位置是距离，亮暗是音色的属性。

一个具体用途：如果你要写一段「越来越亮」的音乐，沿着圈顺时针走是对的（升号越来越多）；如果要「回到原点」，逆时针走回来。

一个能自己做的实验

1. 点 C，听它的主和弦； 2. 顺时针点 G，再点 D； 3. 然后跳过一圈点 D♭（对角）。

你会发现对角那两个调虽然「看起来远」，但它们的关系是「小调 / 大调」 —— 只差三个半音。这就是圈上最反直觉的一层：视觉距离不等于听觉距离。

一个诚实的说明

五度圈是西方调性体系的地图，不是「所有音乐」的地图。

  • 中国的五声音阶不需要调号，所以「它在圈的哪一格」这个问题不成立；
  • 一些民歌在一个调里转来转去，也不需要圈。

圈的价值在于它服务于「转调」这件事 —— 只要你需要换调，圈就是最快的地图。
