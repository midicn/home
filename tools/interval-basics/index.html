首页›音程是什么：八个距离，一次听清

点下面的按钮，先点「▶ C4」听一个音，再点「▶ E4」听另一个，最后点「▶ 合起来」听两个一起响。

这一条要建立的只有一个观念：音程是一个距离，不是一个高度。

为什么「距离」比「高低」重要

如果音程只是「高一点 / 低一点」，那它和「音调高低」是一回事，不是独立的东西。

但一旦把它看成距离，就立刻能解释三件常见的事：

  • 为什么两个音一起响会「融合」 —— 距离近的音重叠得多，听成一个整体；
  • 为什么大三度和小三度都是协和的 —— 它们的距离都足够近，不打架；
  • 为什么九度以上的音程需要被当成「两件事」 —— 距离太远，听成一个音是不成立的。

下面几组就是这个距离的刻度。 每组都是纯一度（小二度）——最小的距离。

八个基本音程

从同一个音出发逐级叠加，这是最基础的一组：

  • 纯一（0 个半音）—— 两个音完全相同
  • 小二（1 个半音）—— 距离最近，但会「撞」
  • 大二（2 个半音）—— 一步级进
  • 小三（3 个半音）
  • 大三（4 个半音）
  • 纯四（5 个半音）—— 听起来「空旷」，folk 里常用
  • 纯五（7 个半音）—— 最协和，跳进八度几乎不显突兀
  • 小六（8 个半音）
  • 大六（9 个半音）
  • 纯八（12 个半音）—— 同名音高八度

先只听三组，把「距离」这件事感受一下，不用记名字。

一个可以自己验证的观察

下面这组是纯八度——C4 和 C5。它们的名字相同，只是高了八度。

如果音程只是"距离"，那纯八度就应该被听成"很远的同一个音"。 确实如此——很多人甚至会把纯八度听成同度。

下一个要试的是纯五（C4 与 G4）。它跨得比八度小，但听起来的"开阔感"反而更强。

这就是协和与开放的区别：八度是同度关系，五度是开放关系。距离和协和度不是同一件事。

先听三组，把「距离」感受一下

第一组：纯一（C4 与 C4）—— 两个音完全相同，听起来只有一个。

第二组：小二（C4 与 D♭4）—— 距离最近，但会「撞」。

第三组：纯四（C4 与 F4）—— 距离中等，但听感是「空旷」。

练习

1. 先只用「合起来」按钮听，不用管名字； 2. 换个顺序再听（先听第二个音再听合起来）——顺序不同，感受会不同； 3. 试过五次以上再去看音名。

「先听得出、再说出名字」是本站视唱练耳那篇的核心，这里用的是同一个方法。

下一步

  • 专门练「听得出」：音程听辨练习
  • 只差半个音的那两种：大三度和小三度
  • 跨八度的那些大跳：复合音程
  • 术语与度数定义：音乐词典的乐理条目。
