使用条款

本站内容的使用条件与行为约定

一、这是什么

本站（midicn.com 及其子域，包括 lib / mid / zip / hist / comp / theo / inst / gen / prod / cn 各站）是由个人维护的免费、非营利的音乐知识内容站。我们的目标是：把音乐是什么、怎么构成、怎么被造出来，尽可能清楚地讲明白。

本站不提供账号、不收费、不做交易。

二、你可以怎么用

本站的文字内容与自绘图表采用 CC BY 4.0 授权。意思是：

  • ✅ 可以自由复制、转载、改写、翻译，包括用于商业用途
  • ✅ 可以挂广告、放进自己的网站或课程材料
  • ⚠️ 唯一的要求是署名：注明来源为本站，并给出链接

本站的代码采用 MIT 授权。

本站引用的曲目（MIDI 文件）不适用上述授权 —— 它们各自属于 midicn-lib 数据集的来源许可，页面上的每一条实例都标注了许可档位（C1 可商用 / C2 非商业 / C3 仅限学习研究）。使用这些曲目时，请以其自身许可为准。

三、请不要这样做

  • ❌ 用自动化程序高频抓取本站（我们带宽有限，且内容本身是开放的，没有必要）
  • ❌ 转载时去掉署名或声称是自己原创
  • ❌ 把本站内容做违反当地法律的使用
  • ❌ 把它当作专业的音乐教学、法律或医疗建议（见 免责声明）

四、内容的准确性

我们尽力核对每一条事实，并在条目末尾列出事实来源。但：

  • 本站内容为通识性说明，不保证绝对无误
  • 音乐史与音乐学的部分问题在学界本身有争议，我们会注明分歧
  • 若发现错误，欢迎指出（见下）

五、条款的变更

本条款可能随站点发展而更新（例如未来引入广告或新功能时）。更新后的版本会替换本页，继续使用即视为接受。重要的变更我们会在此注明日期。

六、联系

发现错误、有版权疑虑、或想授权合作，请通过 GitHub 仓库 提交 issue 或联系维护者。

本页为使用条款的通俗表述，不构成法律意见。涉及具体权利主张时，请咨询专业法律人士。
